# Шектеу іс-шараларын белгілеу туралы

«Ветеринария туралы» Қазақстан Республикасы Заңының 10-1 бабының 7 тармақшасына сәйкес және Қазақстан Республикасы Ауыл шаруашылығы министрлігі Ветеринариялық бақылау және қадағалау комитетінің Қарқаралы аудандық аумақтық инспекциясының бас мемлекеттік ветеринариялық- санитариялық инспекторының 2023 жылғы 11 желтоқсандағы №15-4-1/474 ұсынысы негізінде ШЕШТІМ:

<a id="para_1"></a>

1. Ірі қара малдарының арасында құтыру ауруы анықталуына байланысты, Қарқаралы ауданы, Нұркен Әбдіров ауылдық округінің Жарлы ауылының аумағында шектеу іс-шаралары белгіленсін.

<a id="para_2"></a>

2. Қарқаралы ауданы, Нұркен Әбдіров ауылдық округі әкімінің 2023 жылғы 9 қарашасындағы № 3 «Шектеу іс-шараларын белгілеу туралы» шешімі жойылсын.

<a id="para_3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="para_4"></a>

4. Осы шешім оның алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Н.Әбдіров ауылдық округінің әкімі**

**А. Бейсенбеков**
