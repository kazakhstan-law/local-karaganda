# 2012-2014 жылдарға арналған қалалық бюджет туралы

Қазақстан Республикасының 2008 жылғы 4 желтоқсандағы Бюджет кодексіне, Қазақстан Республикасының 2001 жылғы 23 қаңтардағы "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Заңына сәйкес, қалалық мәслихат ШЕШІМ ЕТТІ:

1. 2012-2014 жылдарға арналған қалалық бюджет 1, 2 және 3 қосымшаларға сәйкес, оның ішінде 2012 жылға келесі көлемдерде бекітілсін:

   1) кірістер - 2903252 мың теңге, оның ішінде:

      салықтық түсімдер - 123034 мың теңге

      салықтық емес түсімдер - 4700 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер - 2300 мың теңге;

      трансферттер түсімі - 2773218 мың теңге;

   2) шығындар - 2911185 мың теңге;

   3) таза бюджеттік несиелеу - 0 мың теңге, оның ішінде:

      бюджеттік несиелер - 0 мың теңге;

      бюджеттік несиелерді өтеу - 0 мың теңге;

   4) қаржы активтерімен операциялар бойынша сальдо - 0 мың теңге, оның ішінде:

      қаржы активтерін сатып алу - 0 мың теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер - 0 мың теңге;

   5) бюджеттің тапшылығы (профициті) - 7933 мың теңге;

   6) бюджеттің тапшылығын қаржыландыру (профицитін пайдалану) - 7933 мың теңге, оның ішінде:

      қарыздар түсімі - 0 мың теңге;

      қарыздарды өтеу - 0 мың теңге;

      бюджет қаражатының пайдаланылатын қалдықтары - 7933 мың теңге.

      > *Ескерту. 1 тармаққа өзгерістер енгізілді - Қарағанды облысы Приозерск қалалық мәслихатының 2012.03.12 N 3/20 (2012.01.01 бастап қолданысқа енеді); 2012.04.10 N 5/39 (2012.01.01 бастап қолданысқа енеді); 2012.05.08 N 6/43 (2012.01.01 бастап қолданысқа енеді); 2012.06.12 N 8/53 (2012.01.01 бастап қолданысқа енеді) шешімдерімен.*

2. 2012 жылға арналған қалалық бюджет түсімдерінің құрамында облыстық бюджеттен қала бюджетіне берілетін субвенциялардың мөлшері 740828 мың теңге сомасында ескерілсін.

3. 2012 жылға арналған ауданның (облыстық маңызы бар қаланың) жергілікті атқарушы органының резерві 2420 мың теңге сомасында бекітілсін.

4. 2012 жылға арналған бюджетті орындау барысында секвестрлеуге жатпайтын жергілікті бюджеттік бағдарламалардың тізбесі 4 қосымшаға сәйкес бекітілсін.

5. 2012 жылға арналған инвестициялық жобаларды іске асыруға бағытталған, жергілікті бюджеттік даму бағдарламаларының тізбесі 5 қосымшаға сәйкес бекітілсін.

6. Осы шешім 2012 жылдың 1 қаңтарынан бастап қолданысқа енеді.
