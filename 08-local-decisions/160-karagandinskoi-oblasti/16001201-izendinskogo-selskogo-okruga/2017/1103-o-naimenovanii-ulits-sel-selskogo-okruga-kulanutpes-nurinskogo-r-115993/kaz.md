# Нұра ауданы Құланөтпес ауылдық округіндегі ауылдарының көшелерін атау туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңына, Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы «Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Заңына және Қарағанды облыстық ономастика комиссиясының 2017 жылғы 4 шілдедегі қорытындысына сәйкес, Нұра ауданы Құланөтпес ауылының әкімі ШЕШІМ ЕТТІ:

<a id="p1"></a>

1. Нұра ауданы Құланөтпес ауылдық округі Ақтүбек ауылындағы атауы жоқ көшеге «Сарыарқа» атауы берілсін.

<a id="p2"></a>

2. Нұра ауданы Құланөтпес ауылдық округі Нығыман ауылындағы атауы жоқ көшеге «Астана» атауы берілсін.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім алғашқы ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
