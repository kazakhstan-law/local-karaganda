# TACIS бағдарламасы бойынша Қазақстан Республикасынан Ұлттық үйлестірушіні тағайындау туралы

Қазақстан Республикасының Үкіметі қаулы етеді:

1. TACIS бағдарламасы бойынша Қазақстан Республикасынан Ұлттық үйлестіруші болып Қазақстан Республикасының Экономика және бюджеттік жоспарлау вице-министрі Ербол Тұрмаханұлы Орынбаев, TACIS бағдарламасы бойынша Қазақстан Республикасынан Ұлттық үйлестірушінің орынбасары болып Қазақстан Республикасының Қаржы вице-министрі Нұрлан Құсайынұлы Рахметов белгіленсін. <*>

   > *Ескерту. 1-тармақ өзгерді - ҚР Үкіметінің 2002.09.20. N 1041*

   қаулысымен. P021041_

2. Мыналардың күші жойылды деп танылсын:

1) "TACIS бағдарламасы бойынша Қазақстан Республикасының Ұлттық үйлестірушісі туралы" Қазақстан Республикасы Министрлер Кабинетінің 1995 жылғы 13 қаңтардағы N 49 P950049_ қаулысы (Қазақстан Республикасының ПҮКЖ-ы, 1995 ж., N 3, 34-құжат);

2) "TACIS бағдарламасы бойынша Қазақстан Республикасынан Ұлттық

```
үйлестірушіні тағайындау туралы" Қазақстан Республикасы Үкіметінің 1999
жылғы 15 қарашадағы N 1712

P991712_

қаулысы (Қазақстан Республикасының
ПҮКЖ-ы, 1999 ж., N 50, 493-құжат).
```
