# Сайлау учаскелерін құру туралы

Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі «Қазақстан Республикасындағы сайлау туралы» Конституциялық заңының 23 бабына сәйкес Қарағанды қаласының әкімі ШЕШІМ ЕТТІ:

1. Сайлау учаскелері осы шешімнің 1,2 қосымшаларына сәйкес құрылсын.

2. Қарағанды қаласы әкімінің кейбір шешімдері осы шешімнің 3 қосымшасына сәйкес күші жойылды деп танылсын.

3. Осы шешімнің орындалуын бақылау Қарағанды қаласы әкімі аппаратының басшысына, Қазыбек би атындағы және Октябрь ауданының әкімдеріне жүктелсін.

4. Осы шешім оны алғаш ресми жариялаған күннен бастап қолданысқа енгізіледі.

**Қарағанды қаласының әкімі**

**Н. Әубәкіров**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an001`](kaz/an001.md) | an001 |
| [`an001-part001`](kaz/an001-part001.md) | `!` Қарағанды қаласының Қазыбек би атындағы аудан бойынша сайлау учаскелері |
| [`an001-part106`](kaz/an001-part106.md) | № 106 сайлау учаскесі жаңа участок |
| [`an002`](kaz/an002.md) | Қарағанды қаласы Әлихан Бөкейхан ауданы бойынша сайлау учаскелері |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
