# Қарағанды облысы бойынша іске асырылуы жоспарланған жергілікті мемлекеттік - жекешелік әріптестік жобаларының тізбесін бекіту туралы

«Мемлекеттік-жекешелік әріптестік туралы» Қазақстан Республикасының 2015 жылғы 31 қазандағы Заңының 24-бабының 1) тармақшасына сәйкес Қарағанды облыстық мәслихаты ШЕШІМ ЕТТІ:

1. Қарағанды облысы бойынша іске асырылуы жоспарланған жергілікті мемлекеттік-жекешелік әріптестік жобаларының тізбесі қосымшаға сәйкес бекітілсін.

2. Осы шешім алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Сессия төрағасы**

**М. Абайділдинов**

**Облыстық мәслихаттың хатшысы**

**С. Өтешов**

> *Қарағанды облыстық*  
> *мәслихатының XV сессиясының*  
> *2018 жылғы 4 мамырдағы*  
> *№308 шешіміне қосымша*

## Қарағанды облысы бойынша іске асырылуы жоспарланған жергілікті мемлекеттік-жекешелік әріптестік жобаларының тізбесі

> *Ескерту. Қосымша жаңа редакцияда – Қарағанды облыстық мәслихатының 08.08.2019 № 439 (алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі); жаңа редакцияда – Қарағанды облыстық мәслихатының 28.11.2019 № 466 (алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі); жаңа редакцияда – Қарағанды облыстық мәслихатының 27.02.2020 № 506 (алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі); жаңа редакцияда – Қарағанды облыстық мәслихатының 02.07.2020 № 552 (алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі) шешімдерімен.*

1. Бұқар жырау ауданындағы Көкпекті ауылында «Нұр-Сәби» жеке меншік балабақшасын жөндеу және пайдалану.

2. Қарағанды облысының Қарағанды қаласында сырғанау айдынын пайдалану.

<a id="p3"></a>

3. Қарағанды қаласында гематология орталығын ашу.

<a id="p4"></a>

4. Саран қаласында гемодиализ орталығын ашу.

<a id="p5"></a>

5. Жезқазған қаласында балаларды оңалту орталығын ашу.

<a id="p6"></a>

6. Теміртау қаласында оңалту орталығын ашу.

<a id="p7"></a>

7. Жезқазған қаласында оңалту орталығын ашу.

<a id="p8"></a>

8. Жаңаарқа ауданында гемодиализ орталығын ашу.

<a id="p9"></a>

9. Қарағанды қаласының «Дарынды бала 4» балабақшасы.

<a id="p10"></a>

10. Қарағанды облысы Шет ауданының Ақсу-Аюлы ауылында 50 орынға арналған балабақша ашу.

<a id="p11"></a>

11. Қарағанды облысы Шет ауданының Ақсу-Аюлы ауылында 40 орынға арналған балабақша ашу.

<a id="p12"></a>

12. Қарағанды облысы Шет ауданының Ақсу-Аюлы ауылында 75 орынға арналған балабақша ашу.

<a id="p13"></a>

13. Қарағанды қаласында 300 орынға арналған облыстық көпсалалы аурухана салу және пайдалану.

<a id="p14"></a>

14. Қарағанды облысының медицина ұйымдарын цифрлық медициналық жабдықпен жарақтандыру.

<a id="p15"></a>

15. Қарағанды қаласында «Ожет» спорт кешенін пайдалану.

<a id="p16"></a>

16. Жезқазған қаласында «Таеквондо орталығын» пайдалану.

<a id="p17"></a>

17. Қарағанды қаласының тұрғындарына мемлекеттік және ағылшын тілдерін оқыту қызметтерін көрсету.

<a id="p18"></a>

18. Сәтбаев қаласында гемодиализ орталығын ашу.

<a id="p19"></a>

19. Қарағанды облысының ауылдық денсаулық сақтау объектілерінде интернет желісіне қолжетімдік үшін спутниктік хабарлар арнасын ұйымдастыру.

<a id="p20"></a>

20. Қарағанды қаласы Октябрь ауданының 11а шағын ауданында емхана салу және одан әрі пайдалану.

<a id="p21"></a>

21. Қарағанды қаласының Октябрь ауданында (Пришахтинск) Балалар емханасын ашу.

<a id="p22"></a>

22. Қарағанды қаласында оңалту орталығын ашу.

<a id="p23"></a>

23. Қарағанды облысының Шахтинск қаласында 25 орынға арналған бөбекжай ашу.

<a id="p24"></a>

24. Қарағанды қаласының Октябрь ауданында емхана ашу (Восток-2 ықшам ауданы).

<a id="p25"></a>

25. Қарағанды қаласында позитронды-эмиссиялық томография орталығын ашу.

<a id="p26"></a>

26. Жезқазған өңірінің медициналық ұйымдары үшін орталықтандырылған медициналық зертхана ашу.

<a id="p27"></a>

27. Қарағанды қаласында маммологиялық орталық ашу.

<a id="p28"></a>

28. Қарағанды қаласының Степной 2 шағын ауданында емхана ашу.

<a id="p29"></a>

29. Балқаш қаласының Злиха Сабитова шағын ауданында емхана салу және одан әрі пайдалану.

<a id="p30"></a>

30. Қарағанды қаласында магнитті-резонансты томография кабинетін ашу.

<a id="p31"></a>

31. Абай, Қарқаралы, Осакаров аудандарында гемодиализ орталықтарын ашу.

<a id="p32"></a>

32. Қарағанды облысының ауылдық денсаулық сақтау объектілерін интернетке қол жеткізу үшін деректерді берудің спутниктік арналарымен қамтамасыз ету.

<a id="p33"></a>

33. Қарағанды қаласында клиникалық-диагностикалық зертхана ашу.

<a id="p34"></a>

34. Теміртау қаласында балаларды оңалту инклюзивті орталығын ашу.

<a id="p35"></a>

35. Қарағанды қаласында сәулелі терапия орталығын ашу.
