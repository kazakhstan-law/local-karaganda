# Шет ауданының Қорғаныс істері жөніндегі біріктірілген бөлімінің шақыру учаскесіне азаматтарды тіркеуді ұйымдастыру туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін – өзі басқару туралы» Заңының 31 бабының 1 тармағының 13) тармақшасына, Қазақстан Республикасының 2012 жылғы 16 ақпандағы «Әскери қызмет және әскери қызметшілердің мәртебесі туралы» Заңының 16 бабының 3 тармағына сәйкес, Шет ауданының әкімі ШЕШІМ ЕТТІ:

<a id="para_1"></a>

1. Шет ауданының Қорғаныс істері жөніндегі біріктірілген бөлімінің шақыру учаскесіне азаматтарды тіркеу, 2019 жылдың қаңтар айынан наурыз айына дейін ұйымдастырылсын.

<a id="para_2"></a>

2. Шет ауданының ауылдық округтер мен кент әкімдері ұландардың Шет ауданының Қорғаныс істері жөніндегі біріктірілген бөлімінің шақыру учаскесіне медициналық комиссияға ұйымдастырушылық және міндетті келуін қамтамасыз етсін.

<a id="para_3"></a>

3. Осы шешімнің орындалуын бақылау Шет ауданы әкімінің орынбасары А. Әбілдинге жүктелсін.

<a id="para_4"></a>

4. Осы шешім оның алғашқы ресми жарияланған күннен кейін күнтізбелік он күн өткен сон қолданысқа енгізіледі.

**Шет ауданының әкімі**

**М.Жандәулетов**
