# Об утверждении Плана по управлению пастбищами и их использованию по Актогайскому району на 2023-2024 годы

В соответствии с Законом Республики Казахстан от 23 января 2001 года «О местном государственном управлении и самоуправлении в Республики Казахстан», Законом Республики Казахстан от 20 февраля 2017 года «О пастбищах», Актогайский районный маслихат РЕШИЛ:

1. Утвердить прилагаемый План по управлению пастбищами и их использованию по Актогайскому району на 2023-2024 годы.

2. Настоящее решение вводится в действие со дня его первого официального опубликования.

**Председатель районного маслихата**

**Р.Абеуов**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an001`](rus/an001.md) | План по управлению пастбищами и их использованию по Актогайскому району на 2023-2024 годы |
| [`an001-part001-t001-r001`](rus/an001-part001-t001-r001.md) | `!` таблица 1, строки 1–1310 |
| [`an001-part001-t001-r002`](rus/an001-part001-t001-r002.md) | таблица 1, строки 1311–1335 |
| [`an003`](rus/an003.md) | Приемлемые схемы пастбищеоборотов |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
